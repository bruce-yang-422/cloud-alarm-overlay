# Cloud Alarm Overlay v1.4.4

本次更新讓你直接從通知視窗完成任務，並以循環時間選擇器調整 Google 日曆提醒，減少操作步驟與時間輸入錯誤。

## 新增功能（Added）

- **從通知視窗完成任務**：新增「已完成」按鈕，記錄通知已讀並完成本次任務。重複任務只完成本次提醒，後續排程照常保留。
- **區分已讀與完成**：原確認按鈕改為「只確認已讀」，關閉通知後保留任務進度；逾期未完成的任務仍顯示「逾期」。

## 改善項目（Changed）

- **日曆提醒時間選擇**：時、分改用循環選擇器，不必手動輸入或捲動長下拉清單。支援滑鼠滾輪、箭頭按鈕與鍵盤上下方向鍵。
- **連續循環調整**：分鐘可從 `59 → 00 → 01`，也可反向調整；小時在 `23 ↔ 00` 循環。時、分獨立調整，分鐘循環不會改變小時。
- **管理員設定範本**：JSON 設定範本與程式內下載的範本統一使用官方更新來源。
- **使用文件**：整理安裝、快速開始與通知操作說明，補充員工名單的雲端同步方式。

## 修正問題（Fixed）

- 保留未修改提醒時間的原始秒數，避免僅切換提醒開關時意外建立自訂提醒時間。

## 使用須知

- 「只確認已讀」與一般提醒自動關閉都不會將任務標記為完成。
- 強制通知的「只確認已讀」與「已完成」操作，均須輸入畫面上的 9 位數字確認碼。
- Google Sheets 與 Google 日曆任務的完成紀錄保存在本機，不會修改雲端資料。
- 預覽、倒數、健康提醒與番茄鐘通知不提供任務完成操作。
- 既有已讀紀錄維持原狀，不會自動轉為任務完成紀錄。

## 安裝與升級

1. 從本頁 **Assets** 下載 `CloudAlarmOverlay-v1.4.4-Setup-x64.exe`。
2. 儲存編輯中的內容；建議先在程式內建立 `.calbak` 備份。
3. 執行安裝檔，依安裝精靈完成安裝。

適用 **Windows x64**，已包含 .NET 執行階段，無須另外安裝 .NET。

v1.4.3 使用者可直接覆蓋升級，保留既有任務、設定、Google 帳號、同步來源與歷史紀錄。安裝器會關閉相同安裝路徑下執行中的程式，請先儲存變更。
