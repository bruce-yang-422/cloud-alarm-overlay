# Cloud Alarm Overlay v1.4.4 發布說明

- 版本：1.4.4
- 日期：2026-10-30（重新封裝）
- 平台：Windows x64
- 比較基準：v1.4.3

本版本在任務通知視窗新增「已完成」操作，讓使用者直接記錄本次任務進度，並保留獨立的「只確認已讀」操作。本次重新封裝另改善 Google 日曆提醒的時間選擇介面，並更新管理員 JSON 設定範本。

## 新增功能

### 從通知視窗完成任務

- 對應現有任務的通知視窗新增「已完成」按鈕，操作後記錄通知簽收與本次任務完成狀態。
- 原確認按鈕在此類通知中改為「只確認已讀」，保留任務待處理狀態。
- 說明文字明確區分已讀與完成；超過預定時間但未完成的任務仍會顯示「逾期」。
- 重複任務只完成本次發生的項目，後續排程持續保留；可在「已完成」分區查看完成紀錄。

## 行為與相容性

### 日曆提醒時間選擇

- 日曆提醒設定改用時、分循環選擇器，無須手動輸入文字或展開長下拉清單。
- 滑鼠停在小時或分鐘數字上即可滾動調整，也可點選上下箭頭，或以 Tab 切換欄位後使用上下方向鍵。
- 向下滾動增加、向上滾動減少；分鐘可連續從 `59 → 00 → 01`，反向則為 `01 → 00 → 59`。小時同樣在 `23 ↔ 00` 循環。
- 小時與分鐘分別調整；分鐘循環不會自動增加或減少小時。
- 未修改時間時保留原始秒數，避免僅切換提醒開關便意外建立自訂時間；修改時間後以分鐘為精度儲存。
- 保留明暗主題及小視窗捲動操作，停用提醒時一併停用時間選擇器。

### 管理員設定範本

- `cao-settings-template.json` 與程式內「下載 JSON 範本」統一使用專案正式更新來源：`https://raw.githubusercontent.com/bruce-yang-422/cloud-alarm-overlay/main/version.json`。
- 兩份範本內容一致，保留 30 天日誌預設值及試算表範例欄位。

### 通知操作

| 操作 | 通知簽收 | 本次任務進度 |
| --- | --- | --- |
| 只確認已讀 | 記錄已讀並關閉通知。 | 維持原狀；逾期任務仍顯示逾期。 |
| 已完成 | 記錄已讀並關閉通知。 | 標記已完成，保留後續重複排程。 |
| 稍後提醒 | 依既有政策延後通知。 | 維持原狀。 |

- 最高級「強制通知」的已讀與完成操作均須輸入正確的 9 位數字確認碼；接受含連字號或連續數字格式。
- 外部來源任務的完成紀錄儲存在本機，不會透過此操作修改 Google Sheets 或 Google 日曆。
- 預覽、倒數、健康工具及番茄鐘通知不提供任務完成操作。
- 一般提醒自動關閉不會標記任務完成。
- 未新增資料庫遷移；沿用 v1.4.3 的任務完成紀錄格式。既有已讀紀錄不會自動轉為完成紀錄。

## 文件更新

- 重整 README，統一安裝、快速開始、通知行為、開發、封裝及貢獻指南的結構。
- 改用 GitHub Releases 作為公開下載入口，避免固定連結與舊版校驗資訊不同步。

## 安裝與升級

1. 建議先建立 `.calbak` 備份，並儲存編輯中的內容。
2. 執行 `CloudAlarmOverlay-v1.4.4-Setup-x64.exe`，依安裝精靈完成升級。
3. 啟動程式，於任務通知視窗選擇「只確認已讀」或「已完成」。

v1.4.3 使用者可直接覆蓋安裝；安裝器會結束相同安裝路徑的舊版程式。既有任務、設定、歷史紀錄與任務完成紀錄沿用。本套件包含 .NET 執行階段，不需另外安裝 .NET SDK。
