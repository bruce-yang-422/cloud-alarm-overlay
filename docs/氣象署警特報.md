# 首頁氣象署發布資訊

首頁的區域天氣下方會在有符合儲存地點的生效公告時顯示小型圖示標籤：地震報告、颱風、海嘯、豪大雨、雷雨、強風、高溫、低溫、濃霧及其他特報。標籤依內容寬度排列，空間不足時換行，支援淺色與深色主題。

滑鼠移至標籤，可查看公告摘要、符合的影響範圍與警戒等級、發布時間、資料來源與最近查詢時間；點擊前往氣象署官方網站。同類別公告合併成一個標籤，摘要列出最新三則，其餘請至官方查詢。

## 資料範圍

- 使用 [NCDR 民生示警公開資料平台](https://alerts.ncdr.nat.gov.tw/web/developer/alerts-rss) 的[生效中 ATOM feed](https://alerts.ncdr.nat.gov.tw/RssAtomFeeds.ashx)，僅採用中央氣象署／原中央氣象局發布的正式公告，不需使用者輸入 API 金鑰。
- 取得 ATOM 中公告的官方 CAP 明細，依已儲存的天氣地點篩選；標題顯示例如「氣象署 · 五股區」。未儲存的設定草稿不影響首頁，變更儲存地點可立即重新篩選已取得的資料。
- 優先比對行政區代碼；同一區域若同時提供縣市與鄉鎮代碼，採鄉鎮範圍。只有縣市代碼的公告依縣市適用。沒有代碼時，僅接受明確的完整行政區名稱或全臺公告，不從摘要提到的地名推測影響範圍。
- 保留各個 CAP info 區塊的範圍與等級，例如新店區的橙色高溫資訊不會套用到五股區。舊版只有縣市的地點依縣市篩選並在提示中標明；建議重新選取鄉鎮市區以提高精度。
- 官方若提供多邊形／圓形區域，使用已設定天氣地點的參考座標比對（公所或主要聚落附近，並非使用者即時定位）。這類結果代表參考座標，不代表整個行政區皆在範圍內。
- 僅有海域、山區等無法精確比對的描述、未知行政區格式或 CAP 下載失敗時，不顯示為確定適用的圖示，改顯示「影響範圍待確認」入口；可點擊查看官方資訊。部分明細失敗不影響已確認的其他公告。
- 地震圖示代表官方已發布且仍在資料有效期間內的地震報告，不是震前預警。依報告列出的受影響縣市篩選，震央的零半徑座標不作為影響範圍。
- 每五分鐘查詢一次，電腦喚醒後重新查詢；溫度與降雨仍沿用 Open-Meteo，每三十分鐘更新。
- 排除測試、演練、取消、尚未生效及已到期的項目。到期標籤隨首頁時鐘刷新移除，不必等待下一次連線。
- 查詢失敗或資料超過十分鐘未確認時，隱藏舊標籤並顯示「警特報暫不可用」，不表示沒有警特報。正常取得且無公告時不占用標籤空間。
- 沒有設定地點或關閉天氣時不連線；關閉天氣會取消進行中的查詢。示警資料不寫入任務、通知排程或連線健康狀態，不發出聲音或彈出通知。

## 驗證

自動化測試涵蓋官方日期格式、來源／狀態／有效期間篩選、重複資料、十種向量圖示、更新頻率、錯誤隔離、停用取消、有效期移除、瀏覽器連結，以及窄版／深色介面。正式首頁整合測試確認警特報標籤與原本天氣預報按鈕分開操作。

區域篩選測試另涵蓋縣市／鄉鎮代碼、台／臺別名、同公告不同等級、地震各縣市震度範圍、地理圖形與邊界、不明範圍、明細失敗，以及切換已儲存地點。
