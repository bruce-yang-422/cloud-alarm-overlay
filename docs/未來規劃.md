### Google 日曆選用寫回

任務編輯器可指定 Google 帳號與目標日曆，個人使用者可選擇寫回模式，不需本機管理員權限。

| 模式 | 儲存行為 |
| --- | --- |
| 不同步（預設） | 僅儲存本機，不寫入或詢問。 |
| 自動同步 | 儲存已指定目標的任務時建立或更新對應行程。 |
| 每次儲存詢問 | 顯示帳號、日曆及差異，可同步、只儲存本機或取消。 |

- 寫回與現有日曆讀取分開；背景同步及「恢復 Google 設定」不得反向寫入。
- 保存帳號、日曆與行程識別，持續更新同一行程，避免重複新增。
- 區分行程開始／結束與提醒時間；農曆、假日略過及提醒等級須定義映射限制。
- 關閉寫回不刪除線上行程；重新開啟不立即補送歷史變更。本機刪除不自動刪除雲端。
- 本機儲存與雲端結果分開呈現；離線保留本機變更，重試前確認結果，衝突不得靜默覆蓋。
- 實作時驗證三種模式、取消、模式切換、多帳號、權限變更、逾時及重複寫入防護。

### 集中設定下發

- **現況**：通知政策（閃爍時間、安靜模式及鎖定）、同步連結鎖定等設定存在各台電腦，IT 要調整時須逐台登入管理者專區修改。
- **構想**：Sheet A 新增 `Settings` 分頁，程式同步時一併讀取並套用，IT 改一次即生效於全公司。

| Key | Value | Locked | Note |
| --- | --- | --- | --- |
| `SyncIntervalSeconds` | `45` | `TRUE` | 同步間隔（30–60） |
| `FlashMilliseconds` | `800` | `TRUE` | 提醒閃爍時間 |
| `AllowUrgentSnooze` | `TRUE` | `TRUE` | 緊急提醒是否可延後 |
| `RuntimeLogRetentionDays` | `30` | `TRUE` | 執行日誌保留天數 |

以上為規劃中的設定格式，尚未提供雲端下發功能。

- **規則**：
  - `Locked=TRUE`：強制套用，使用者與本機管理者都不能修改，介面沿用現有的鎖定圖示並顯示「由公司設定」。
  - `Locked=FALSE`：作為預設值，使用者可自行調整。
  - 只接受白名單內的 Key 與合法範圍；不認得或不合法的值略過並寫入同步紀錄。
  - 同步失敗時保留上次成功套用的設定。
- **注意**：
  - Sheet A 以公開連結讀取，**不可放密碼、金鑰或任何機密**；結束程式密碼、管理者密碼不納入下發。
  - 與既有的本機鎖定設定合併時，以 Sheet 鎖定優先；需在文件說明優先順序。
  - 舊版程式會忽略 `Settings` 分頁，不影響既有同步；`Sheet範例/` 需新增範例 CSV 與欄位說明。

### 番茄鐘背景音

- **現況**：番茄鐘只有階段結束的提示音（`SoundService` 以 Windows `PlaySound` 播放單次音效），沒有專注時的背景音。
- **構想**：番茄鐘設定新增「背景音」，專注期間循環播放，幫助進入專注狀態。
- **音源**：
  - 白噪音、粉紅噪音、棕噪音：由程式即時產生，不需音檔、沒有授權問題，也不增加安裝檔大小。
  - 雨聲、咖啡廳、森林等環境音：採用 CC0 等可商用授權素材，隨安裝檔附上，並比照 Emoji 素材附授權聲明。
- **操作**：選擇音源、音量；可選「僅專注時播放」或「休息時也播放」；開始、暫停、結束時淡入淡出。
- **注意**：
  - 背景音改用 WPF `MediaPlayer` 或音訊串流播放，才能循環與調整音量；與現有提示音分開。
  - 任何提醒彈出時自動降低背景音量或暫停，避免蓋過提醒音效；確認後恢復。
  - 預設關閉；程式結束或番茄鐘停止時必定停止播放。

### 訂閱外部行事曆

規劃加入通用 ICS 唯讀訂閱，與現有 Google API 自有日曆同步共用顯示及提醒規則，避免同一日曆重複提醒。

- **構想**：在設定新增「行事曆訂閱」，貼上 ICS 訂閱網址（Google 日曆的「iCal 格式私人網址」、Outlook 的「發佈行事曆」連結），程式定期讀取，自動在事件前提醒。
- **設定項目**：訂閱名稱、網址、提前提醒時間（例如 10 分鐘前）、提醒等級（一般或重要）、全天事件是否提醒、啟用／停用。
- **顯示**：行事曆事件在「我的任務」與首頁以「行事曆」來源標示，唯讀不可編輯；可依訂閱整批停用。
- **更新**：每 15–30 分鐘重新讀取；事件新增、修改、刪除會同步反映。讀取失敗時保留上次結果，並在側邊欄狀態顯示該訂閱異常。
- **注意**：
  - ICS 需處理重複規則（RRULE）、例外日期（EXDATE）、時區與全天事件，建議使用成熟套件（例如 MIT 授權的 Ical.Net），新增套件須更新 `packages.lock.json`。
  - 私人 iCal 網址等同存取權，只存在本機；介面與日誌中遮蔽顯示，備份時提示是否包含。
  - 只讀取、不寫回外部行事曆。
  - 與既有的「行事曆（ICS）匯出」構想方向相反，可共用 ICS 解析與產生元件。

## 待評估構想

以下尚未採納或排期；實作前須重新確認需求及相依條件。

### 錯過提醒摘要

- **現況**：關機或休眠期間錯過的通知只寫入歷史紀錄，不會補跳。
- **構想**：開機或喚醒後，在系統匣或首頁顯示一則「你錯過了 N 則提醒」的摘要，列出清單，可逐筆確認或一次標記已讀。
- **注意**：只摘要、不補跳個別通知，避免開機時一次跳出一大堆視窗。

### 多螢幕顯示緊急與強制通知

- **現況**：`AlarmWindow` 依主螢幕尺寸定位，緊急與強制通知只出現在主螢幕。
- **構想**：強制通知在每個螢幕都顯示遮罩，確認碼輸入框放在主螢幕；緊急通知可選擇顯示在滑鼠所在的螢幕。
- **注意**：需驗證不同 DPI 縮放的多螢幕組合。

### 確認回報集中查看

- **現況**：確認紀錄只存在各台電腦，管理者無法集中看到誰已確認強制通知。
- **構想**：用 Google Apps Script 網頁應用程式或 Google 表單接收確認結果，寫入 Sheet C，讓管理者看到每則通知的簽收率；簽收與任務完成須分開統計。
- **注意**：這會新增通知簽收資料的雲端傳送，需要評估隱私、公司政策與網路失敗重送機制，建議預設關閉。

### 程式內自動下載更新

- **現況**：程式讀取 `version.json` 檢查版本，下載則交給瀏覽器，使用者要自己執行安裝檔。
- **構想**：程式直接下載安裝檔，比對 `version.json` 中的 SHA-256，驗證無誤後詢問是否立即安裝。
- **注意**：雜湊不符時必須拒絕執行；下載來源限定 GitHub Releases 網域。

### 快速新增與任務範本

- **現況**：新增任務須開啟主視窗並填寫完整表單。
- **構想**：加上全域快捷鍵，開啟精簡的快速新增視窗；常用任務（例如每月報表、週會）可存成範本，一鍵套用。
- **注意**：快捷鍵要能自訂，並偵測是否與其他程式衝突。

### 行事曆（ICS）匯出

- **構想**：將本機任務與倒數事件匯出為 `.ics`，匯入 Outlook 或 Google 日曆。
- **注意**：農曆與「假日略過」規則無法完整轉成 ICS 的重複規則，可改為展開未來一年的個別日期。

### 番茄鐘綁定任務

- **構想**：開始番茄鐘時可選擇對應的任務，統計每個任務累積的專注時間，歷史紀錄可依任務篩選。

### GitHub Actions 自動測試

- **現況**：儲存庫沒有 CI，測試靠手動執行。
- **構想**：推送或建立 PR 時，在 `windows-latest` 執行 `dotnet test`；另可在建立標籤時自動建置發布檔。
- **注意**：WPF 測試需要 Windows runner；截圖類測試可能要另外處理。

### 自動備份排程

- **現況**：備份須由管理者手動建立。
- **構想**：每週或每次升級前，自動在本機建立 `.calbak`，保留最近 N 份；升級安裝前先備份，降低資料庫遷移失敗的風險。

### 移除未使用的占位服務

- **現況**：`HolidayService`、`LunarScheduleService`、`OverdueGraceService` 是 Milestone 0 占位實作，呼叫即拋例外，仍在 DI 註冊但沒有程式使用；實際判斷已在 `TaskSchedulingService`。
- **構想**：移除三個類別、介面與註冊，減少誤用風險。

### 首次登入強制變更預設管理者密碼

- **現況**：新資料庫預設帳密 `admin`／`12345`，且公開於 README，只提醒使用者自行變更。
- **構想**：以預設帳密登入時，須先設定 8–128 字的新密碼才能進入管理者專區；已變更密碼的電腦不受影響。

### 天氣延伸

- 評估依明日降雨機率提供帶傘提醒。
- 評估增加第二個預報來源；採用前確認資料服務授權、配額與來源標示。
