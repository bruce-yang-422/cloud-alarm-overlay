## 功能進度與構想

### 忙碌中稍後提醒

> ✅ CAO-018 已納入本機 v1.3.0，尚未公開發布。一般、重要、緊急與強制任務可延後 5／10／15／30 分鐘，單次上限 3 次；管理者可關閉緊急提醒延後。

- **已實作**：提醒視窗提供「忙碌中，稍後提醒」；延後次數與最後確認時間納入歷史和 CSV，重開程式不補跳。倒數通知與番茄鐘不在本次任務延後範圍。
- **構想**：上班忙碌、一時無法處理時，按「忙碌中，稍後提醒」延後 5～30 分鐘再通知；用詞避免「貪睡」，強調是工作中暫緩處理。
- **注意**：強制通知可直接延後、不需輸入確認碼，正式確認仍需驗證碼；設定延後次數上限，管理者可關閉緊急提醒的延後。

### 首頁天氣（今天與明天）

> ✅ CAO-019 已納入本機 v1.3.0，尚未公開發布。首頁顯示現在天氣與明天預報，支援個人地點、公司預設與關閉天氣。

- **顯示**：現在溫度與降雨量（mm）、明天最低／最高溫及降雨機率（%）；提示包含體感溫度、預報時間、更新時間與資料來源。窄視窗自動換行，點擊天氣卡以預設瀏覽器開啟已儲存行政區的中央氣象署預報；地點修改從「設定 → 天氣」操作。
- **雙層選單**：「縣市 → 鄉鎮市區」，內建 22 縣市、368 區域，個人設定與公司設定共用。
- **內建搜尋**：以本機選單搜尋地名，支援台／臺、空白分隔關鍵字與全形數字，不需呼叫地名搜尋 API。
- **郵遞區號快選**：支援 3 碼及貼上 5／6 碼，以前 3 碼比對行政區；共用郵遞區號列出全部符合項目，由使用者選擇，不自行猜選。
- **套用方式**：點選搜尋結果會同步雙層選單，唯一結果可按 Enter；仍須儲存才套用，切換縣市會清除舊區域。
- **座標精度**：344 個區域採公所／行政中心，24 個採聚落代表位置，均核對落在行政區內。取得的是該座標的網格預報，不是逐街道觀測或全行政區平均。
- **資料來源**：天氣使用 Open-Meteo，介面標示來源與授權；地點資料來源、授權及更新方法見 [地點資料說明](../src/CloudAlarmOverlay.Core/Data/README.md)。公司部署前仍應確認天氣服務授權適用性。
- **更新與快取**：啟動及喚醒後更新，平時每 30 分鐘更新；保留最後成功結果，超過 6 小時顯示暫不可用。天氣失敗不影響提醒或同步狀態。
- **位置與連線**：不使用 IP 定位；關閉並儲存後停止天氣連線。現有地點選單不需開放 Geocoding API，預報使用 `api.open-meteo.com`。
- **測試**：以固定回應驗證預報，不在自動測試呼叫真實 API；涵蓋行政區、郵遞區號歧義、選單連動與明暗主題。

**尚未實作的延伸**：依明天降雨機率提供帶傘提醒，或增加中央氣象署等第二來源，仍為選配構想。

### 本機任務 CSV 匯入

> ✅ CAO-020 已納入本機 v1.3.0，尚未公開發布。支援選檔預覽、逐列勾選、重複編號略過／換新編號、匯出與下載兩筆範例。

- **已實作**：「我的任務」新增 CSV 匯入／匯出與範本；任務產生器新增 CSV 匯出。UTF-8 含 BOM 可直接匯入，Big5 會提示改存 UTF-8。
- **構想**：在「我的任務」新增「匯入 CSV」，一次建立多筆本機任務，例如整年的繳費日、換電腦時搬移任務，或把任務產生器匯出的資料轉成本機任務。同時加上「匯出本機任務 CSV」，匯出格式與匯入相同，方便搬移與批次修改後再匯入。
- **格式**：沿用 Sheet `Tasks` 分頁的欄位（第 1 列英文標題、第 2 列中文說明），可直接重用 `CsvSheetParser.ParseTasks`；任務產生器匯出的檔案也能直接匯入。`TargetDeviceOrName`、`ExcludeDeviceOrName` 對本機任務無意義，匯入時忽略。
- **流程**：選檔 → 預覽清單（標示有效、錯誤原因、與既有任務重複）→ 勾選要匯入的列 → 確認建立；全部匯入後顯示成功與略過筆數。
- **注意**：
  - 匯入的任務一律是本機任務，不影響雲端任務。
  - 單次任務時間已過的列標示錯誤並略過；重複任務依規則計算下一次提醒（與 CAO-006 一致）。
  - `Id` 與既有本機任務重複時，可選擇略過或改用新編號，不覆蓋既有任務。
  - 支援 UTF-8（含 BOM）；Excel 另存的 Big5 CSV 需偵測或提示改存 UTF-8。
  - 提供「下載範本 CSV」按鈕，範本含兩列範例。

### 倒數卡片分享圖

> ✅ CAO-021 已納入本機 v1.3.0，待實機驗收；尚未公開發布。

- **現況**：倒數／正數卡片、資料表操作列及首頁倒數釘選卡已提供「分享圖片」。
- **構想**：在倒數卡片的操作選單加上「分享圖片」，產生一張可傳到 LINE 或社群的圖片，例如「距離日本旅行還有 30 天」、「我們在一起 1,000 天」。
- **內容**：事件名稱、剩餘／已過天數（沿用卡片的顯示方式：天數、週＋天、月＋天、年＋月＋天）、目標／起始日期、分類圖示；右下角小字標示程式名稱，可在設定中關閉。
- **輸出**：
  - 「複製到剪貼簿」可直接貼到 LINE、Teams；「另存 PNG」存檔。
  - 尺寸可選 **1:1 正方形 1080×1080** 與 **2:3 直式 1080×1620**，預覽與輸出保持所選比例。

- **注意**：
  - 圖片以產生當下的數字為準；時間型倒數顯示到「天」即可，避免秒數立即過時。
  - 備註內容預設不放進圖片，避免無意間分享私人資訊。
  - 以高 DPI 輸出，確保文字與 emoji 清晰。

### 集中設定下發

> ✅ 已採納，尚未實作、尚未登記 CAO 編號。

- **現況**：通知政策（閃爍時間、安靜模式及鎖定）、同步連結鎖定等設定存在各台電腦，IT 要調整時須逐台登入管理者專區修改。
- **構想**：Sheet A 新增 `Settings` 分頁，程式同步時一併讀取並套用，IT 改一次即生效於全公司。

| Key | Value | Locked | Note |
| --- | --- | --- | --- |
| `SyncIntervalSeconds` | `45` | `TRUE` | 同步間隔（30–60） |
| `FlashMilliseconds` | `800` | `TRUE` | 提醒閃爍時間 |
| `SnoozeMaxCount` | `3` | `TRUE` | 稍後提醒上限（CAO-018） |
| `WeatherDefaultLocation` | `台北市` | `FALSE` | 天氣預設地點（CAO-019） |

- **規則**：
  - `Locked=TRUE`：強制套用，使用者與本機管理者都不能修改，介面沿用現有的鎖定圖示並顯示「由公司設定」。
  - `Locked=FALSE`：作為預設值，使用者可自行調整。
  - 只接受白名單內的 Key 與合法範圍；不認得或不合法的值略過並寫入同步紀錄。
  - 同步失敗時保留上次成功套用的設定。
- **注意**：
  - Sheet A 以公開連結讀取，**不可放密碼、金鑰或任何機密**；結束程式密碼、管理者密碼不納入下發。
  - 與既有的本機鎖定設定合併時，以 Sheet 鎖定優先；需在文件說明優先順序。
  - 舊版程式會忽略 `Settings` 分頁，不影響既有同步；`Sheet範例/` 需新增範例 CSV 與欄位說明。

- **構想**：番茄鐘設定新增「背景音」，專注期間循環播放，幫助進入專注狀態。
- **音源**：
  - 白噪音、粉紅噪音、棕噪音：由程式即時產生，不需音檔、沒有授權問題，也不增加安裝檔大小。
  - 雨聲、咖啡廳、森林等環境音：採用 CC0 等可商用授權素材，隨安裝檔附上，並比照 Emoji 素材附授權聲明。
- **操作**：選擇音源、音量；可選「僅專注時播放」或「休息時也播放」；開始、暫停、結束時淡入淡出。
- **注意**：
  - 背景音改用 WPF `MediaPlayer` 或音訊串流播放，才能循環與調整音量；與現有提示音分開。
  - 任何提醒彈出時自動降低背景音量或暫停，避免蓋過提醒音效；確認後恢復。
  - 預設關閉；程式結束或番茄鐘停止時必定停止播放。

### 訂閱外部行事曆

> ✅ 已採納，尚未實作、尚未登記 CAO 編號。

- **現況**：公司或個人行事曆（Google 日曆、Outlook）的會議與行程，須在本程式重複建立才能收到提醒。
- **構想**：在設定新增「行事曆訂閱」，貼上 ICS 訂閱網址（Google 日曆的「iCal 格式私人網址」、Outlook 的「發佈行事曆」連結），程式定期讀取，自動在事件前提醒。
- **設定項目**：訂閱名稱、網址、提前提醒時間（例如 10 分鐘前）、提醒等級（一般或重要）、全天事件是否提醒、啟用／停用。
- **顯示**：行事曆事件在「我的任務」與首頁以「行事曆」來源標示，唯讀不可編輯；可依訂閱整批停用。
- **更新**：每 15–30 分鐘重新讀取；事件新增、修改、刪除會同步反映。讀取失敗時保留上次結果，並在側邊欄狀態顯示該訂閱異常。
- **注意**：
  - ICS 需處理重複規則（RRULE）、例外日期（EXDATE）、時區與全天事件，建議使用成熟套件（例如 MIT 授權的 Ical.Net），新增套件須更新 `packages.lock.json`。
  - 私人 iCal 網址等同存取權，只存在本機；介面與日誌中遮蔽顯示，備份時提示是否包含。
  - 只讀取、不寫回外部行事曆。
  - 與既有的「行事曆（ICS）匯出」構想方向相反，可共用 ICS 解析與產生元件。

### 錯過提醒摘要

- **現況**：關機或休眠期間錯過的通知只寫入歷史紀錄，不會補跳。
- **構想**：開機或喚醒後，在系統匣或首頁顯示一則「你錯過了 N 則提醒」的摘要，列出清單，可逐筆確認或一次標記已讀。
- **注意**：只摘要、不補跳個別通知，避免開機時一次跳出一大堆視窗。

### 多螢幕顯示緊急與強制通知

- **現況**：`AlarmWindow` 依主螢幕尺寸定位，緊急與強制通知只出現在主螢幕。
- **構想**：強制通知在每個螢幕都顯示遮罩，確認碼輸入框放在主螢幕；緊急通知可選擇顯示在滑鼠所在的螢幕。
- **注意**：需驗證不同 DPI 縮放的多螢幕組合。

### 確認回報集中查看

- **現況**：確認紀錄只存在各台電腦，管理者無法集中看到誰已確認強制通知。
- **構想**：用 Google Apps Script 網頁應用程式或 Google 表單接收確認結果，寫入 Sheet C，讓管理者看到每則通知的完成率。
- **注意**：這會改變目前「程式不回寫雲端」的設計原則，需要評估隱私、公司政策與網路失敗重送機制，建議預設關閉。

### 程式內自動下載更新

- **現況**：程式讀取 `version.json` 檢查版本，下載則交給瀏覽器，使用者要自己執行安裝檔。
- **構想**：程式直接下載安裝檔，比對 `version.json` 中的 SHA-256，驗證無誤後詢問是否立即安裝。
- **注意**：雜湊不符時必須拒絕執行；下載來源限定 GitHub Releases 網域。

### 快速新增與任務範本

- **現況**：新增任務須開啟主視窗並填寫完整表單。
- **構想**：加上全域快捷鍵，開啟精簡的快速新增視窗；常用任務（例如每月報表、週會）可存成範本，一鍵套用。
- **注意**：快捷鍵要能自訂，並偵測是否與其他程式衝突。

### 行事曆（ICS）匯出

- **構想**：將本機任務與倒數事件匯出為 `.ics`，匯入 Outlook 或 Google 日曆。
- **注意**：農曆與「假日略過」規則無法完整轉成 ICS 的重複規則，可改為展開未來一年的個別日期。

### 番茄鐘綁定任務

- **構想**：開始番茄鐘時可選擇對應的任務，統計每個任務累積的專注時間，歷史紀錄可依任務篩選。

## 優化構想

### 每月農曆改用內建曆法

> ✅ 已實作，已納入本機 v1.3.0 安裝檔。農曆由 .NET 內建 `ChineseLunisolarCalendar` 換算；節氣繼續使用 Sheet A 的 `LunarCalendar`。

- **提醒排程**：每月初一／十五等日期、每年指定農曆月日，皆在本機計算。任務、倒數、預覽與分享圖片使用相同規則，不受 Sheet 農曆欄缺漏或錯誤影響。
- **首頁顯示**：今日與下一次提醒的農曆直接換算；節氣仍讀取 `LunarCalendar.SolarTerm`，無資料時顯示「-」，讀取失敗時顯示暫不可用。
- **閏月與日期**：每月農曆包含閏月；每年農曆沿用是否包含閏月的選項。小月沒有三十時略過該月，不改成月底提醒；超出內建曆法範圍不猜日期。
- **相容性**：保留既有 `LunarDay:`／`LunarDate:` 規則、Sheet 分頁、GID 與 CSV 欄位，不需重建任務或資料庫遷移；舊農曆對照欄位不再參與排程。
- **驗證**：2026–2027 既有 730 筆農曆日期逐日比對一致；涵蓋閏月、三十、小月、2028 年無對照資料與支援範圍邊界。
- **仍需維護**：Sheet 的節氣、國定假日及補班日。這次未改為內建節氣計算。

### 任務產生器離線化

- **已實作**：Tailwind 預編譯 CSS、固定版本 Lucide、SheetJS 與三套字型皆改由 `task-builder-assets` 提供，隨程式建置與發佈配送，不再依賴 CDN。
- **雲端資料為輔助**：Google Sheet 任務與員工名單讀取失敗，仍可手動新增、編輯目標／排除對象，並匯出 Excel／CSV；未載入的雲端編號無法檢查重複。
- **驗證**：瀏覽器阻擋外網、模擬 Sheet 讀取失敗，驗證本機 HTTP 與直接開啟 HTML 均可操作；本機服務測試包含資源類型與不合法路徑。
- **維護**：資源約 5.5 MiB，版本、授權及重建流程見 [資源說明](../task-builder-assets/README.md)。修改 Tailwind class 後須重新產生 CSS；此變更已納入本機 v1.3.0 安裝檔。

### GitHub Actions 自動測試

- **現況**：儲存庫沒有 CI，測試靠手動執行。
- **構想**：推送或建立 PR 時，在 `windows-latest` 執行 `dotnet test`；另可在建立標籤時自動建置發布檔。
- **注意**：WPF 測試需要 Windows runner；截圖類測試可能要另外處理。

### 日誌自動清理

> ✅ 已實作，已納入本機 v1.3.0 安裝檔。

- **預設**：保留最近 30 個本機日曆日（含今天）的 `logs/runtime-yyyyMMdd.log`，按檔名日期判斷；今天與未來日期不刪除。
- **管理者設定**：「管理者專區 → 本機設定 → 日誌自動清理」，可輸入 1–365 天並儲存，無須重啟。
- **執行時機**：資料庫初始化後啟動檢查，之後每小時檢查；設定修改於下次檢查生效，最晚一小時內。
- **範圍**：僅處理日誌資料夾直屬且名稱／日期合法的 runtime 日誌，不遞迴子資料夾、不跟隨連結；不刪除任務歷史、同步紀錄、稽核紀錄、資料庫或備份。
- **失敗處理**：被占用或無權限的檔案略過，下次再試；不影響提醒。未設定或舊資料值無效時回到 30 天。
- **部署**：管理員 JSON 匯入／匯出及通用範本支援 `RuntimeLogRetentionDays`；省略時保留原設定。保留天數的修改寫入操作稽核。

### 自動備份排程

- **現況**：備份須由管理者手動建立。
- **構想**：每週或每次升級前，自動在本機建立 `.calbak`，保留最近 N 份；升級安裝前先備份，降低資料庫遷移失敗的風險。

### 移除未使用的占位服務

- **現況**：`HolidayService`、`LunarScheduleService`、`OverdueGraceService` 是 Milestone 0 占位實作，呼叫即拋例外，仍在 DI 註冊但沒有程式使用；實際判斷已在 `TaskSchedulingService`。
- **構想**：移除三個類別、介面與註冊，減少誤用風險。

### 首次登入強制變更預設管理者密碼

- **現況**：新資料庫預設帳密 `admin`／`12345`，且公開於 README，只提醒使用者自行變更。
- **構想**：以預設帳密登入時，須先設定 8–128 字的新密碼才能進入管理者專區；已變更密碼的電腦不受影響。
