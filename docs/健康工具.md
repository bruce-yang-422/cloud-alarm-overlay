# 健康工具（v1.4.0）

從左側「健康工具」進入首頁，頂端採兩端半圓的膠囊式滑動分段控制（Sliding Segmented Control），選中底色以 160 毫秒滑動切換，共五個子頁：首頁、喝水、久坐、螢幕休息、伸展。首頁提供啟用工具數、今日通知次數、等待項目、下次預計提醒、功能入口卡片、今日時間軸及最近七天趨勢。點入口卡片會切換到對應子頁。

四個功能子頁各自提供提醒設定、目前狀態、個別七天趨勢與提醒紀錄；切換頁籤保留未儲存的輸入，按「儲存設定」才生效。「還原設定」捨棄該頁草稿，回復上次儲存值。「共同設定」以右側面板提供左邊／置中／右邊顯示位置（預設右邊），以及自動對齊／覆蓋／延後三種番茄鐘協調模式（預設延後），並非第六個分頁。舊版協調開關開啟時沿用「延後」，關閉時沿用「覆蓋」。

四項預設關閉，預設間隔依序為 60、60、20、90 分鐘，時段為 08:30–18:00、自訂星期一至五。各功能子頁可啟停及調整 5–240 分鐘的間隔、同日有效時段與提醒日期。有效時段需長於間隔，目前不支援跨午夜時段。

「提醒日期」提供三種選項，按「儲存設定」後生效：

- **每天**：包含週末與假日。
- **工作日**：一般為週一至週五，略過已載入的假日，補班日照常提醒。使用與月曆共用的假日資料，背景每分鐘重新檢查資料異動；未載入特殊日期時，依一般週一至週五判斷。
- **自訂星期**：依勾選星期提醒，不隨假日或補班日調整。既有設定沿用此模式；切換模式仍保留原有星期選擇。

四項工具可各自選擇日期模式。工作日篩選也適用於番茄鐘自動對齊與延後通知。

## 排程與番茄鐘

- 每日以有效時段開始時間為基準，一個週期後第一次提醒。例如 08:30 開始、每 60 分鐘，排程為 09:30、10:30、11:30，結束時間本身不提醒。
- 開啟功能、修改設定或重新啟動程式後，從下一個排程點開始，不補發之前的提醒。
- **自動對齊**：開始番茄鐘後，等首次要求休息時，一次提醒所有已啟用且當時在有效時段內的工具，即使尚未到原訂時間。按「開始休息」啟動原番茄鐘休息；首次短休息或長休息結束時，以該時間重算各工具週期。之後各自正常提醒，不在每輪休息重新對齊。重設番茄鐘或重啟程式後，下一個工作階段可再次對齊；當天已建立的週期基準會保留至工具設定變更、模式切換或翌日。
- **覆蓋**：依各工具排程正常提醒，即使番茄鐘正在專注。健康提醒不會停止、重設或改變番茄鐘。
- **延後（預設）**：專注執行中先等待，專注結束進入「等待確認」時合併至番茄鐘通知；按「開始休息」仍由原番茄鐘流程啟動休息。原始週期不變，暫停、閒置或休息時可正常提醒。
- 同類只保留一個待提醒項目。延後模式的 30 分鐘上限從最早未處理的原訂時間起算，新的到期項目不延長期限。
- 健康提醒使用無聲、置頂且不取得鍵盤焦點的面板，占主螢幕工作區寬度 30%、填滿工作區高度，保留工作列。可設定左邊、置中或右邊，預設右邊；文字與確定按鈕加大，必須按「確定」才關閉。多項合併，已有健康通知時更新同一面板；合併至番茄鐘通知時也採此版型，保留開始休息的確認流程。
- 同類顯示後 5 分鐘內的下一個排程點記為「近期已提醒，略過」，後續排程仍維持原時間軸。
- 全域勿擾優先於最大延後時間，限制新提醒顯示；已顯示的面板持續等候確認。健康通知不播放音效。離開有效時段、鎖定或睡眠時清除待提醒。恢復或重新啟動時不補跳。
- 「暫停今日提醒」只作用於健康工具；翌日解除暫停，依工具有效日期及時段恢復。

## 統計與資料

一次合併通知算一次「通知」，內含每種工具各算一個「提醒項目」。顯示面板時記錄「已顯示」，按下「確定」或合併番茄鐘的確認才記錄「已確認」，不推定已喝水或已完成活動。

健康資料保留最近七個日曆日。設定、下一次排程、待提醒身分及歷史以 `HealthToolsV1` 設定文件原子儲存於現有 SQLite 資料庫，包含於既有備份及還原流程，不新增資料庫遷移。歷史紀錄頁的一般任務／番茄鐘紀錄不混入健康通知。
