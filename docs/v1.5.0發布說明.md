# Cloud Alarm Overlay v1.5.0

新增程式內下載更新與 ICS 行事曆匯出，可直接驗證並安裝更新，或將多年任務與重要日期帶到 Outlook、Google 日曆。

## 程式內下載更新

- 在「設定 → 軟體更新」直接下載安裝檔，顯示下載進度，也可取消。
- 下載來源限定 HTTPS GitHub Releases，並逐段檢查 GitHub 官方檔案 CDN 的重新導向。
- 比對 `version.json` 的 SHA-256，驗證成功後詢問是否立即安裝；也可稍後在更新頁按「立即安裝」。
- 啟動安裝前會再次驗證。缺少有效雜湊、檔案不完整或雜湊不符時拒絕執行；取消或失敗的未完成下載會清除。

## ICS 行事曆匯出

- 從「我的任務 → 資料工具 → 匯出行事曆（ICS）」或倒數／正數頁右上方開啟。
- 可匯出本機任務、倒數／正數事件，並選擇是否包含停用項目、已完成項目與提醒；雲端來源不會重複匯出。
- 提供 1、3、5、10 年及自訂日期，單次最多 100 年、50,000 個事件；先預覽事件數量，再儲存 `.ics`。
- 日期月曆具備亮／暗色主題底色並保持在視窗左右邊界內，可直接點選日期；起訖日期顛倒時會明確指出迄日不能早於起日。
- 重複排程展開成期間內的個別日期，支援農曆、閏月、略過假日及補班日。農曆計算支援至 2101/01/28，超出期間會提示調整。
- 保留全天與跨日活動，時間依本機時區匯出；沒有活動期間的定時事件以 30 分鐘呈現。

## 使用須知

- 未來國定假日與補班日需要資料支援，超出已知假日涵蓋期間時，預覽會提示可能不完整。匯出後的公告變更不會自動同步至日曆。
- ICS 為靜態快照；外部日曆的提醒與重複匯入行為可能不同，建議先匯入獨立日曆確認。
- 原本的通知簽收、手動確認與強制通知政策不會轉成外部日曆的強制操作。

## 安裝與升級

適用 **Windows x64**，安裝套件已包含 .NET 執行階段，無須另行安裝 .NET。

v1.4.6 及更早版本請先手動執行 `CloudAlarmOverlay-v1.5.0-Setup-x64.exe` 升級，才能使用新的程式內下載流程。v1.4.6 可直接覆蓋安裝，保留既有本機資料、設定與 Google 連線。

安裝前請儲存編輯內容，建議先建立 `.calbak` 備份；安裝程式會關閉相同安裝路徑下的舊程式，再引導完成更新。
