# Cloud Alarm Overlay v1.4.1

修正 [v1.4.0](https://github.com/bruce-yang-422/cloud-alarm-overlay/releases/tag/v1.4.0) 在全新電腦首次啟動時無法開啟的問題。已在使用 v1.4.0 的電腦不受影響，仍建議更新。

> 2026-10-02 已發布，[下載安裝檔](https://github.com/bruce-yang-422/cloud-alarm-overlay/releases/download/v1.4.1/CloudAlarmOverlay-v1.4.1-Setup-x64.exe)。

## 問題修正

- **首次設定畫面啟動失敗**：在未設定過的電腦安裝 v1.4.0 後，「設定這台電腦」畫面會跳出「啟動失敗：Index was outside the bounds of the array.」並關閉程式。原因是「個人使用／公司使用」尚未選擇時，分段選單的滑動指示條讀取了不存在的項目；現在未選擇時會隱藏指示條，可正常完成首次設定。

## 安裝與升級

下載並執行 **`CloudAlarmOverlay-v1.4.1-Setup-x64.exe`**。適用 Windows x64，安裝包包含執行所需元件，不需另外安裝 .NET SDK。

已安裝 v1.4.0 或更早版本可直接覆蓋升級，不必先移除；任務、設定與歷史資料皆保留。v1.4.0 首次設定失敗的電腦，直接安裝本版即可，無須清除資料。
