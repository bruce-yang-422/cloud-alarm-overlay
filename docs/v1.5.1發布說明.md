# Cloud Alarm Overlay v1.5.1

改善提醒通知的資訊層次、閱讀空間與操作區，支援寬窄版及深淺色顯示；日曆提醒的小時與分鐘支援直接輸入，減少設定時間時的重複操作。

## 提醒通知 UI 優化

- 採用圓角卡片、柔和陰影與向量圖示，清楚呈現通知來源、標題及提醒時間。
- 通知內容與補充備註集中於內容卡片，長內容可捲動閱讀，底部操作按鈕保持可見。
- 寬版將稍後提醒與確認操作分置左右；窄版自動分行，改善小型通知的操作空間。
- 深淺色模式套用一致的按鈕與延後時間選單配色，保留各提醒等級的識別色。
- 標題圖示依任務、重複排程、雲端來源、行事曆、緊急／強制通知、健康提醒與番茄鐘切換，窄版通知同樣顯示圖示。
- 修正操作按鈕文字被通用文字樣式覆蓋的問題，確保完成按鈕在各提醒等級與深淺色模式下清楚可讀。
- 已讀與完成選項採相同配色與尺寸，所有提醒等級及深淺色模式均以中性文案說明兩者差異；一般任務改用清單圖示。
- 可拖曳一般通知的標題列移動視窗；最高等級全螢幕通知與健康提醒側欄維持原有位置規則。

## 提醒操作

保留稍後提醒、已讀確認、任務完成及最高等級確認碼驗證。「只確認已讀」保留任務待處理狀態，「已完成」會完成本次任務。

## 日曆提醒時間輸入

- Google 日曆行程的「提醒設定」中，小時、分鐘可點選後直接輸入數字，例如將分鐘直接改為 `45`，不必逐次點擊箭頭。
- 點入欄位時自動全選原有數字，方便快速覆寫；也可使用 Tab 鍵切換欄位。
- 保留箭頭、滾輪及上下方向鍵循環微調；輸入單位數後，離開欄位或儲存時會自動補零。
- 採用 24 小時制，儲存時檢查小時 `0–23`、分鐘 `0–59`；空白、非數字或超出範圍時會提示並移至對應欄位，修正後才能儲存。

## 安裝與升級

適用 **Windows x64**，安裝套件已包含 .NET 執行階段，無須另行安裝 .NET。

執行 `CloudAlarmOverlay-v1.5.1-Setup-x64.exe` 可覆蓋安裝並保留既有任務、設定與歷史紀錄。安裝前請儲存編輯內容；安裝程式會關閉相同安裝路徑下的舊程式。
