# Cloud Alarm Overlay v1.4.0

相較 [v1.3.0](v1.3.0發布說明.md)，本版新增任務月曆與跨日活動、喝水與休息提醒、依所在地篩選的氣象警特報，並重新規劃首頁、設定與管理者專區，讓今天的提醒、重要追蹤與需要處理的問題更容易掌握。

> 2026-09-30 已完成本機測試封裝，包含任務月曆、最新首頁與氣象等調整，待安裝驗收後正式發布。Google 帳號整合尚未對所有使用者開放。

## 新增功能

### 任務月曆與跨日活動

- 「我的任務」可切換**清單／月曆**，沿用搜尋與來源篩選；支援切換月份、返回今天、點選日期查看當日所有項目。
- 月曆預設以星期日為每週第一天，可在「設定 → 外觀與視窗」選擇星期日到星期六任一天，自動儲存並隨本機備份保留。六日標題與日期、已載入的平日假日以紅字顯示；補班日使用一般日期色並標示「補班」。
- 日期格顯示**農曆日期、假日名稱與節氣**，右側「當日工作」提供所選日期的完整資訊。農曆由本機換算，假日與節氣使用已載入的日曆資料。
- 選取日期以淡色底與外框持續標示；按「今天」會選取並捲動至今天，切換操作焦點後仍保留框選效果。
- 新增活動可填開始與結束日期／時間，例如**週五 10:00 至週一 20:00 的寵物展**，跨週、跨月會接續顯示。
- **全天日期區間包含結束日**，例如 10/1～10/10 的慢性處方箋領藥期間；同日項目過多時可展開當日清單。
- **活動期間與提醒時間獨立**。新增活動預設不通知，可另外啟用一次提醒；關閉提醒仍保留月曆活動。區間活動目前不支援重複規則，每週、每月等其他重複提醒仍會投影在月曆。
- 「每天」、「每個工作日」及每週七天的固定任務不占用月曆主格，集中於右側「當日工作 → 日常任務」，以精簡時間與名稱顯示。依既有假日略過與補班規則列出，沿用搜尋及來源篩選；清單與提醒排程照常運作。
- Google 日曆於下次成功同步後補入活動結束時間及全天區間；本機提醒調整不會改動活動期間，也不會寫回 Google。
- 本機活動期間隨備份及 CSV 保存。CSV 的 `ActivityEndAt` 為不含此時刻的結束時間，全天 10/1～10/10 會記為 10/11 00:00；畫面仍顯示 10/10。
- 新備份格式為第 4 版，仍可讀取舊備份；新版備份請以 v1.4.0 還原。

### 健康提醒：喝水、久坐、螢幕休息與伸展

- 四項提醒可分別啟用，**預設全部關閉**。可設定 **5–240 分鐘**的間隔、提醒時段與適用星期。
- 提醒日期可選「每天／工作日／自訂星期」。工作日依已載入的假日與補班資料調整，四項工具可各自設定；既有星期選擇保持為自訂模式。
- 健康工具頁提供目前狀態、下一次提醒、今日紀錄與最近七天趨勢，各項工具也有獨立設定與紀錄。
- 多項到期提醒會合併呈現，使用無聲置頂面板，可選左側、中央或右側；閱讀後按「確定」關閉。
- 可「暫停今日提醒」，或隨時恢復；翌日依原設定恢復排程。
- 支援與番茄鐘配合：**自動對齊**於首次休息銜接提醒並重設週期、**照常提醒（覆蓋）**依各工具時間執行，或使用預設的**延後**模式，在專注結束時合併提醒，最長延後 30 分鐘。全域勿擾仍優先適用。
- 關機、睡眠或離開有效時段後，不補跳已錯過的健康提醒。統計記錄通知顯示與確認，不代表已完成喝水或運動。

詳細操作見[健康工具](健康工具.md)。

### 首頁重新規劃

首頁集中呈現當下提醒與今日進度，主要操作移至頁首，減少重複卡片與大型功能按鈕。

| 區域 | 顯示內容 |
| --- | --- |
| 精簡資訊列 | 日期、農曆、現在時間、節氣與區域天氣 |
| 下一個提醒 | 任務名稱、說明、提醒等級、日期與時間、剩餘時間；可直接查看提醒內容 |
| 今日進度 | 已確認／今日總數、進度條、待處理與其中逾時未確認的數量 |
| 重要追蹤 | 已釘選的任務與倒數／正數；保留取消釘選、分享及進度資訊 |
| 需要處理 | 僅在本機排程中斷、來源同步失敗、授權失效或資料過期等異常時顯示，提供明細與處理入口 |
| 健康提醒 | 啟用健康工具後才顯示，只列已啟用項目的狀態、提醒倒數與今日提醒次數；暫停時顯示暫停狀態 |

移除首頁下方「即將到來的任務」清單與原本的常用功能、雲端同步狀態卡。一般連線摘要保留於左下角，異常才占用首頁的處理區。

重要追蹤沿用任務與倒數共用的 **2–5 項**釘選上限；多於兩項時在區塊內捲動，不拉長左側卡片。單項釘選也維持適當比例。

### 依地區顯示氣象署發布資訊

- 在首頁天氣下方，以對應圖示顯示所在地適用且生效中的地震報告、颱風、海嘯、豪大雨、雷雨、強風、高溫、低溫、濃霧等資訊。
- 依「設定 → 首頁與天氣」**已儲存的地點**比對官方公告範圍；縣市公告依縣市、鄉鎮公告依鄉鎮篩選。同一公告包含不同地區等級時，保留所在地對應的資訊。
- 滑鼠停留可查看公告摘要、影響範圍、警戒等級及更新時間；點擊開啟官方網站。
- 每 **5 分鐘**查詢，無須另外輸入 API 金鑰；目前溫度與降雨預報仍沿用每 30 分鐘更新。
- 無法判斷影響範圍時提供「影響範圍待確認」入口；查詢失敗或資料過久未確認時顯示暫不可用。沒有適用公告時不占用標籤空間。
- 地震資訊是**已發布的地震報告**。此功能顯示官方資訊，不提供震前預警，也不另發聲音或彈出通知。

詳細資料來源與範圍判斷見[氣象署警特報](氣象署警特報.md)。

## 設定與管理介面改善

### 個人設定重新分類

以分組側欄取代橫向大量頁籤，將相關功能放在同一個操作脈絡：

| 分組 | 子功能 |
| --- | --- |
| 提醒通知 | 通知音效、勿擾與顯示 |
| 個人偏好 | 外觀與視窗、首頁與天氣、編輯與分享 |
| 帳號與應用程式 | Google 帳號與同步、軟體更新、我的裝置 |

調整選單箭頭、分段選項、按鈕比例、行距與留白，支援淺色／深色外觀及較小視窗。「我的裝置」置於最後；有未儲存修改的設定頁，在離開前提供處理提示。

### 管理者專區重新分類

- **連線與資料**：共用試算表、農曆與假日。
- **政策與安全**：使用者政策、安全與存取。
- **維護與診斷**：啟動與更新、備份與移轉、紀錄查詢、清理與重置。
- 提供總覽入口，整理測試連線、儲存與狀態回饋，減少重複提示及過多層框線。
- 自訂 Google 登入專案保留於管理者專區的進階設定，預設收合；一般帳號登入與來源管理放在個人設定。

### 軟體更新說明更易閱讀

- 一般使用者可在「設定 → 軟體更新」查看目前版本、公開版本與更新內容，再選擇是否下載。
- `version.json` 的 `releaseNote` 支援 Markdown 標題、粗體、清單與連結，採適當閱讀寬度、行高及段落間距。
- 舊版多行純文字說明會整理為條列，避免整段文字擠在一起；公開版本與本機相同或較舊時，也會標示版本關係。
- 管理者專區只保留更新來源設定，下載與版本說明集中於個人設定。

## Google 帳號整合（尚未公開開放）

本版已實作以下整合，現階段供可授權帳號測試；一般使用者的公開登入仍待開放。本機提醒、健康工具及既有公開 Sheet A／B 同步不受影響。

### 多帳號與私人來源

- 可同時連接多個 Google 帳號，替帳號自行命名，例如「工作排程」「家庭生活」，並在清單中查看各帳號的來源與狀態。
- 使用者在「設定 → Google 帳號與同步」管理私人 Google Sheets 任務及自己擁有的 Google 日曆，不需登入本機管理員。
- 程式內建預設 Google 登入設定，使用者不需自行建立 Google Cloud 專案或匯入設定檔。自訂專案屬進階選用功能。
- 連線明細依帳號列出各來源、最後成功時間及錯誤原因；已停用來源不列為故障。

### 個人日曆提醒可在本機調整

- 首次同步採用 Google 的彈出式提醒；行程沿用日曆預設值時，採用該日曆的預設提醒。若有多個，使用最早的彈出式提醒；未設定時先關閉本程式提醒。
- 可在「我的任務」切換是否提醒，並編輯本機提醒日期與時間。自訂值在重新同步與重啟後仍保留。
- 「恢復 Google 設定」清除本機調整，套用最近成功同步的提醒參數，之後繼續跟隨 Google。
- 自訂日期／時間後，即使線上行程改期，也會保留已指定的本機時間；重複行程的各次實例分別設定。
- **本機調整不會寫回 Google 日曆線上版**；日曆雙向寫回仍屬未來規劃。

### Google Sheets 線上任務編輯

取得帳號的 Sheets 編輯授權，並另行開啟來源寫回後，可在獨立視窗新增、修改或刪除 Tasks 任務。送出前提供差異確認，偵測到雲端異動時要求重新讀取；適用於沒有其他人或程式同時編輯的 Tasks 表。

Google 授權憑證不包含於一般設定匯出或本機備份，移轉電腦後需重新登入。詳細功能、權限與限制見[Google 帳號與同步設定](Google帳號與同步設定.md)。

## 安裝與升級

本機測試安裝檔為 **`CloudAlarmOverlay-v1.4.0-Setup-x64.exe`**，適用 Windows x64，包含執行所需元件，不需另外安裝 .NET SDK。

升級前請先儲存編輯內容並建立本機備份。程式包含保留既有任務、設定與歷史的資料庫升級流程；從 v1.3.0 覆蓋升級的完整安裝流程，仍待以最終安裝包驗收。

提醒需保持程式執行，關閉主視窗後會常駐系統匣。
