# Cloud Alarm Overlay v1.4.3

相較 v1.4.2，本版加入任務進度分區與完成操作，修正高 DPI 螢幕的預設視窗空間與倒數環文字顯示，並加入保留同步來源的 Google 帳號重新登入與大頭貼顯示功能。

## 任務進度與清單

- **進度分區**：「我的任務」預設顯示「待處理」，可切換「已完成／已結束／全部」；搜尋、來源篩選與分區數量同步更新。
- **明確標記完成**：本機與外部來源任務皆可單筆或批次完成，完成後移至完成區；可恢復待處理，或使用操作提示中的「復原」。外部任務的完成紀錄保留於本機，不會修改 Google 或試算表。
- **區分進度與提醒**：任務進度與提醒開關分開呈現；逾期未完成仍列為待處理，已結束的活動另行分類，通知簽收不會自動視為任務完成。
- **重複任務逐次完成**：完成其中一次提醒後，保留該次完成紀錄，後續排程繼續顯示於待處理，避免整個重複任務消失。
- **月曆同步分區**：月曆依每次任務的進度篩選，可完成或恢復選取的任務。
- **精簡清單欄位**：重複規則移到任務名稱下方，縮減欄位與工具列空間；完成區保留紀錄並限制誤刪或修改原任務的操作。

## 視窗與倒數顯示

- **預設視窗隨顯示縮放調整**：修正固定實體像素尺寸在 4K 螢幕上造成排版空間不足、首頁與側邊導覽出現捲軸的問題。工作區足夠時，保留至少 1344×960 WPF 排版單位；4K／150% 預設為 **2016×1440**、4K／200% 為 **2688×1920 實體像素**。
- **保留緊湊間距**：100% 縮放下，1080p／1200p 預設為 1344×960，1440p 及更高解析度為 1400×1000。工作區不足時等比例縮小，仍可手動放大或最大化。
- **倒數環加大**：首頁倒數環由 88×88 改為 **128×128 WPF 排版單位**，時間文字自動等比例縮小，讓「23時59分」「59分59秒」與較長天數完整位於圓環內；適用 16:9、21:9 與不同顯示縮放。

## Google 帳號與同步

- **新增重新登入入口**：需要重新驗證時，可直接按帳號卡片的「重新登入」，或從「••• → 重新登入…」開啟 Google 授權，無須刪除帳號再新增。
- **保留帳號與來源**：重新登入保留帳號名稱、同步來源 ID、啟用狀態與其他帳號；成功後重設該帳號來源的失敗等待，讓啟用的來源繼續依排程同步。
- **確認原帳號與完整權限**：選錯 Google 帳號、取消登入或未授予原來源所需的完整權限，不會覆蓋原連線。
- **修正憑證失效誤判**：憑證更新端點回覆 HTTP 401 時保留憑證供重試，避免將 OAuth 用戶端設定問題直接判為使用者授權遭撤銷；Google 明確回覆 `invalid_grant` 時才標記續期授權失效。
- **修正來源帳號篩選文字**：選單顯示帳號名稱，不再顯示 `GoogleAccount {...}` 物件內容。
- **自動顯示 Google 大頭貼**：登入或重新登入時取得 Google 提供的照片，憑證續期時更新照片網址；無照片、離線或下載失敗時使用預設人像，不影響同步。

Google OAuth 專案若仍為外部 Testing 狀態，使用 Sheets／日曆權限的更新憑證通常在七天後到期；此期限需由 OAuth 專案管理者依 Google 規則調整發布設定，桌面程式無法延長。[Google 憑證期限規則](https://developers.google.com/identity/protocols/oauth2#expiration)

## 安裝與升級

執行 **`CloudAlarmOverlay-v1.4.3-Setup-x64.exe`**。適用 Windows x64，安裝包包含執行所需元件，不需另外安裝 .NET SDK。

已安裝 v1.4.2 可直接覆蓋升級，保留既有任務、設定、Google 帳號與同步來源。安裝後重新啟動程式，以套用新的預設視窗尺寸；已失效的 Google 授權可使用「重新登入」恢復。

既有帳號若尚未提供大頭貼，可使用「••• → 重新登入…」授予 `profile` 個人資料權限，不需刪除帳號或重建來源。

任務完成紀錄會自動建立儲存結構；本機任務的完成紀錄納入備份，並保留讀取既有備份的相容性。既有簽收紀錄保留，任務完成需另行明確標記。
