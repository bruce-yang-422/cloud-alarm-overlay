# Cloud Alarm Overlay v1.3.0

相較 [v1.2.0](https://github.com/bruce-yang-422/cloud-alarm-overlay/releases/tag/v1.2.0)，本版新增「忙碌中，稍後提醒」、首頁天氣、本機任務 CSV 匯入與倒數分享圖片，並改善設定搬移、離線使用及清單閱讀空間。

## 新增功能

### 忙碌中，稍後提醒

- 一般、重要、緊急與強制任務可選擇延後 **5／10／15／30 分鐘**，每次通知最多延後 3 次。
- 強制通知按「稍後提醒」不需輸入驗證碼；正式確認仍需驗證碼。管理員可關閉緊急提醒的延後功能。
- 歷史紀錄與匯出資料會記錄延後次數。重開程式後不補跳已錯過的延後通知；倒數及番茄鐘通知不適用這項功能。

### 首頁天氣與詳細預報

- 顯示**現在溫度、降雨量**及**明天最低／最高溫、降雨機率**。
- 內建臺灣 **22 縣市／368 鄉鎮市區**選單，可用地名關鍵字或郵遞區號快選；支援個人地點、公司預設與關閉天氣。
- 每 30 分鐘更新，啟動及休眠喚醒後重新取得資料；連線失敗保留最後成功結果，超過 6 小時顯示暫不可用。
- 點擊天氣卡，以預設瀏覽器開啟該行政區的**中央氣象署預報**；滑鼠停留可查看預報及更新時間。
- 首頁數值來源為 **Open-Meteo**，屬所在地座標的網格預報；不使用 IP 定位。

### 本機任務 CSV 匯入／匯出

- 可先預覽、檢查錯誤並勾選要匯入的列，再批次建立本機任務。
- 遇到重複編號可略過或產生新編號；不覆蓋既有任務，也不修改雲端資料。
- 提供匯出與兩筆範例的 CSV 範本，任務產生器也能匯出相同格式。請使用 UTF-8 CSV。

### 倒數／正數分享圖片

- v1.2.0 的倒數／正數事件新增「分享圖片」，可另存 PNG 或複製到剪貼簿。
- 提供 **1:1 正方形（1080×1080）**與 **2:3 直式（1080×1620）**，搭配三種背景、六種色彩風格與明暗模式。
- 圖片包含事件名稱、剩餘／累計時間及日期，不包含備註；可關閉程式名稱標示。

## 相較 v1.2.0 的操作改善

| 項目 | v1.2.0 | v1.3.0 |
| --- | --- | --- |
| 我的任務 | 多組操作按鈕常駐 | CSV 收進「資料工具」，依單選／多選顯示操作，增加清單空間 |
| 提醒紀錄 | 大型統計卡與完整篩選區 | 精簡統計摘要、來源／結果下拉選單，日期預設收合並顯示區間 |
| 番茄鐘歷程 | 卡片與篩選區占用較多高度 | 保留彩色統計卡與留白，縮減高度，日期可展開調整 |
| 左下角狀態 | 本機排程及兩個 Sheet 的文字狀態 | 圓角狀態卡、整體徽章與分列圓點，保留異常原因提示 |
| 任務產生器 | 樣式、圖示及 Excel 元件依賴 CDN | 資源與字型隨程式配送，斷網仍可手動建立及匯出任務 |
| 每月農曆 | 排程依賴 Sheet 農曆對照資料 | 改用 .NET 內建曆法，首頁農曆也在本機換算 |

任務產生器另改善浮動選時、分鐘微調與即時時間建議。Google Sheet 任務及員工名單仍需網路；讀取失敗時可手動輸入，但無法檢查尚未載入的雲端重複編號。

農曆小月沒有三十時會略過該月，每月農曆包含閏月；每年農曆沿用既有閏月選項。**節氣仍使用 Sheet A 的 `LunarCalendar`，假日及補班日仍使用 `Holidays`**。本版同步更新 2026–2027 範例資料，使用中的 Sheet 請自行確認已更新。

## 管理與維護

- **JSON 設定匯入／匯出**：管理員登入後，可下載範本、匯入同步來源與通知政策等參數，或匯出目前已儲存的設定，減少逐台重填。匯出不包含管理員密碼與未儲存修改；JSON 為明文，含公司連線資訊的檔案請妥善保管。
- **日誌自動清理**：預設保留最近 **30 天**，管理者專區可調整為 **1–365 天**。啟動後及每小時清理過期執行日誌，不刪除任務歷史、資料庫紀錄或備份。

## 安裝與升級

下載並執行 **`CloudAlarmOverlay-v1.3.0-Setup-x64.exe`**。適用 Windows x64，安裝包包含執行所需元件，不需另外安裝 .NET SDK。

已安裝 v1.2.0 可直接覆蓋升級，不必先移除。升級前請先儲存編輯內容並建立本機備份；安裝器會關閉原安裝位置的舊程式，首次啟動自動升級本機資料庫，保留既有任務、設定與歷史資料。

提醒仍需保持程式執行，關閉主視窗後會常駐系統匣。
