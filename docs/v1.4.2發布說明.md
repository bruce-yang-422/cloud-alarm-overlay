# Cloud Alarm Overlay v1.4.2

相較 v1.4.1，本版調整高解析度與 21:9 螢幕的預設視窗尺寸，縮小首頁與側邊導覽的元件間距；天氣地點統一由使用者設定，首頁警特報移到天氣右側。

## 介面調整

- **2K 與超寬螢幕預設尺寸縮小**：2560×1440、3440×1440（21:9）、2560×1600，以及更高解析度螢幕，預設視窗由 1792×1280 改為 **1400×1000 實體像素**。
- **1920×1200 預設尺寸縮小**：由 1540×1100 改為 **1344×960**；1920×1080 維持 1344×960。
- **首頁版面更緊湊**：縮小內容外框、卡片內距、卡片欄間距與倒數環尺寸，並縮減今日進度區的留白；文字大小維持可讀。
- **側邊導覽間距縮小**：減少導覽按鈕的上下內距與按鈕間距。
- **天氣地點統一由使用者設定**：移除管理員通知政策中的公司預設地點，以及管理員設定檔的天氣匯入／匯出項目；改由「設定 → 首頁與天氣」選擇地點。
- **天氣警特報移到右側**：警特報與目前天氣並排，使用首頁資訊列的右側空白區；窄視窗自動換行，關閉天氣時一併隱藏。
- **清除天氣地點**：原「使用預設地點」改為「清除地點」，儲存後首頁提示選擇地點。

## 問題修正

- 修正顯示縮放下原生視窗尺寸取整後，最小尺寸可能略大於實際預設尺寸的問題。
- 移除管理員與使用者天氣表單共用選取狀態造成的互相干擾。
- 修正首頁自動排版時「警特報暫不可用」文字可能被壓成零寬度而無法顯示的問題。

## 安裝與升級

執行 **`CloudAlarmOverlay-v1.4.2-Setup-x64.exe`**。適用 Windows x64，安裝包包含執行所需元件，不需另外安裝 .NET SDK。

已安裝 v1.4.1 可直接覆蓋升級，保留既有任務、設定與歷史資料。

從 v1.4.1 升級時，會將原先生效的公司預設天氣地點保留為本機地點，既有個人地點優先保留。使用者清除並儲存後，重新啟動不會恢復公司預設；管理員 JSON 中的天氣欄位不再套用，其他設定仍可匯入。

預設視窗仍採 7:5 比例，依啟動螢幕的 DPI 換算；工作區不足時等比例縮小。可手動拉大或最大化，從系統匣重新開啟會保留本次執行期間調整的尺寸。
