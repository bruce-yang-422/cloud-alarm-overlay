# Cloud Alarm Overlay v1.4.5

本次更新調整任務產生器的員工操作範圍，移除強制通知建立入口，並保護無法在產生器編輯的重複規則，避免意外改變排程。

## 改善項目（Changed）

- **員工提醒等級**：任務產生器僅提供「一般提醒」「重要提醒」「緊急提醒」。強制通知由管理者透過公司管理流程設定。
- **草稿檢查**：新增任務、複製資料列及匯出 CSV／Excel 時，會檢查提醒等級；含強制通知的草稿須先移除該項目才能匯出。
- **確認選項說明**：將 `RequireAck` 顯示名稱調整為「要求手動確認」，與強制通知等級明確區分。
- **規則說明**：補充任務產生器與程式使用的重複規則格式，以及星期日、指定月份與農曆日期的對應方式。

## 修正問題（Fixed）

- 編輯產生器尚不支援的重複規則（例如每年指定農曆月日 `LunarDate`）時，會提示改由程式內任務編輯器或管理者調整，保留原始資料，避免誤轉為其他排程。

## 使用須知

- 雲端既有強制通知仍可在產生器唯讀預覽，不會加入草稿匯出；接收端的強制通知行為維持原有政策。
- 「要求手動確認」只控制通知的確認方式，不會將一般、重要或緊急提醒升級為強制通知。
- 產生器目前提供不重複、每天、工作日、每週、每月及農曆每月日期；尚未提供每年指定農曆月日的選項。

## 安裝與升級

1. 從本頁 **Assets** 下載 `CloudAlarmOverlay-v1.4.5-Setup-x64.exe`。
2. 儲存編輯中的內容；建議先在程式內建立 `.calbak` 備份。
3. 執行安裝檔，依安裝精靈完成安裝。升級後，請關閉既有任務產生器分頁，從程式重新開啟。

適用 **Windows x64**，已包含 .NET 執行階段，無須另外安裝 .NET。

v1.4.4 使用者可直接覆蓋升級，保留既有任務、設定、Google 帳號、同步來源與歷史紀錄。安裝器會關閉相同安裝路徑下執行中的程式，請先儲存變更。
