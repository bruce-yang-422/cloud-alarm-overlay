# 管理者專區 UI／UX 重整提案

狀態：使用者已確認，2026-09-29 已套用至正式 WPF 程式。以下保留功能清點與設計決策。HTML 原型與暫存截圖已於實作完成後清理。

## 1. 建議採用的架構

把七個等寬分頁改成分組側邊導覽，保留內容區給實際操作。功能不刪除；將散落在一般設定的管理操作收回管理區。

```text
管理者專區
├─ 總覽                         新增入口：組合現有狀態與功能捷徑
├─ 連線與資料
│  ├─ 共用試算表                 Sheet A／B、測試、同步
│  └─ 農曆與假日                 離線資料、GitHub 更新
├─ 政策與安全
│  ├─ 使用者政策                 通知限制、公司預設天氣
│  └─ 安全與存取                 管理者帳密、結束程式保護
│     └─ 進階：自訂 Google 登入  小型收合入口，預設不展開
└─ 維護與診斷
   ├─ 啟動與更新                 Windows 自動啟動、更新來源網址
   ├─ 備份與移轉                 .calbak 備份還原、管理設定 JSON
   ├─ 紀錄查詢                   同步紀錄／系統事件／操作稽核
   └─ 清理與重置                 日誌保留、舊紀錄清理、恢復初始狀態
```

共 1 個總覽與 8 個功能頁，以三個群組呈現。只有「紀錄查詢」保留三個短選項切換資料種類；其他頁面不用多層膠囊或分頁。

### Google 登入的產品定位（依本次使用者確認更新）

公開發行版本使用程式內建的桌面 OAuth 用戶端設定（`google-desktop-oauth.local.json`）；一般使用者與陌生下載者直接點選 Google 登入並授權，不需要自行建立 Google Cloud 專案或匯入 JSON。這是產品預設流程，不代表目前 Google 公開授權審查已完成。

自訂用戶端功能保留，定位為少數組織需要的冷門進階功能。取消獨立側欄項目及總覽捷徑，改放「管理者專區 → 安全與存取」頁面底部的小型文字入口「進階：自訂 Google 登入」。預設收合，使用者主動展開後，才顯示目前設定、匯入、恢復程式預設與說明。不得把匯入 JSON 呈現成一般登入前必做步驟，也不在首次啟動或正常登入流程推廣這個入口。

### 管理範圍必須說清楚

這是此電腦、目前 Windows 使用者的應用程式管理區，並非遠端公司管理平台。「公司預設」不代表會推送設定到其他電腦。公司模式保留管理登入與固定 10 分鐘有效期；個人模式保留現有直接使用方式。

## 2. 現況問題與解法

| 現況 | 操作困擾 | 提案 |
|---|---|---|
| 本機設定包含清理、帳密、啟動、通知、天氣、結束密碼 | 很難由名稱猜到功能在哪 | 按用途拆到政策、安全、啟動、清理 |
| 同步來源放管理 JSON 匯入／匯出 | 誤以為 JSON 只有來源設定 | 搬到備份與移轉，標示支援的設定範圍 |
| 系統紀錄再包分頁，稽核卻是另一大分頁 | 查詢操作與日期條件分散 | 一個紀錄工作區，統一日期與匯出工具列 |
| 上方標題、提示、分頁、子分頁占太多高度 | 真正表單被壓到狹小捲動區 | 短頁首、分組導覽、單一主要捲動區 |
| 開關有些立即儲存，有些要按儲存 | 難以判斷修改是否生效 | 表單草稿＋明確儲存；即時命令另列，已依確認實作 |
| 管理更新網址、全部重置仍在一般設定 | 使用者看到不能操作的管理欄位 | 管理欄位搬入；個人的檢查更新功能保留 |
| 大面積藍底、同權重按鈕、過寬膠囊 | 視覺焦點不明 | 中性色底、少量強調色、文字適寬控制項、明確主次操作 |

## 4. 每頁的操作優先順序

| 頁面 | 先看到 | 往下／進階 | 主要操作 |
|---|---|---|---|
| 總覽 | 模式、範圍、現有來源狀態 | 政策、安全與維護入口 | 前往對應功能，不做裝飾性統計 |
| 共用試算表 | 來源 A、B 名稱與測試／同步狀態 | 來源欄位、工作表 GID、詳細結果 | 儲存並同步；測試為次要操作 |
| 農曆與假日 | 資料版本、範圍、上次結果 | 更新規則；進階來源網址收合 | 儲存設定；立即更新為獨立命令 |
| 使用者政策 | 通知限制、可編輯欄位 | 公司預設天氣 | 整頁儲存政策（新增一致流程） |
| 安全與存取 | 管理者身分、登入期限、結束保護模式 | 帳密對話框；頁底小型「進階：自訂 Google 登入」預設收合 | 密碼不長駐表單；自訂 OAuth 主動展開才可設定 |
| 啟動與更新 | 自動啟動、目前版本 | 管理用更新網址 | 儲存啟動／更新設定（新增一致流程） |
| 備份與移轉 | 本機資料備份／還原 | 管理 JSON 匯入／匯出／範本 | 分開兩種檔案，不能一個模糊「匯入」 |
| 紀錄查詢 | 種類、日期、查詢、匯出 | 可捲動資料表與完整訊息 | 查詢；表格占大部分可用高度 |
| 清理與重置 | 執行日誌保留 | 舊成功紀錄清理；最下方獨立重置區 | 正常儲存與危險操作視覺分離 |

## 5. 版面與視覺規格

- 保留程式原有主導覽；第 02 版原型呈現完整程式視窗，依 MainWindow.xaml 使用 184 DIP 主導覽、54 DIP 頂部列，放入品牌圖、裝置標示與連線狀態區，其他主功能只示意原有位置。取消管理區七個上方分頁，以 176 DIP 的內部導覽呈現三組功能。
- 一般表單內容最大寬約 1000 DIP，靠內容區左側，左右留白約 22 DIP；不把每個輸入框拉滿整個螢幕。紀錄表格可使用更多寬度。
- 當「管理工作區本身」寬度不超過 850 DIP，內部導覽改為選單抽屜；不超過 720 DIP 才把表單改單欄。Sheet A／B 在內容足夠寬時並排，來源鎖定與共用間隔合成短工具列。維持主程式 1050×680 DIP 的最小視窗，原型不以手機尺寸取代桌面驗收。
- 8／12／16／24／32 DIP 間距節奏；一般文字 13–14 DIP、輔助文字 12–13 DIP、頁標題 22–24 DIP；行高約 1.5。這是提案數值，不冒稱作業系統硬性規範。
- 按鈕與輸入約 34–38 DIP 高，切換開關約 36×20 DIP。短選項依文字寬度排列；頻率等使用短下拉，取消整列超寬膠囊。
- 白／淺灰內容、中性灰導覽、深灰文字；藍色只用於目前選取、焦點與主要操作。成功、警示附文字，不只有紅綠點。
- 選取項目使用淺底＋短強調條＋字重；鍵盤焦點另有清楚外框，與滑鼠懸停、目前頁面三者可區分。
- 頁首只留標題、一句範圍說明與真正必要的命令。表單只用一個主要捲動區；不在大卡片內再塞小捲動區。
- 表單草稿有變更才出現固定底部「放棄變更／儲存」列；即時命令不偽裝成表單儲存。
- 深色模式使用相同階層與操作語意，避免單純反白；原型可切換檢視。

## 6. 既有搬移與新增互動，分開核准

**既有功能重新整理**：上述功能分組、命名、次序、表格工具列、按鈕主次、色彩間距；個人 Google 帳號保持在一般設定；自訂 OAuth 降為安全頁底部的預設收合入口；JSON 與 .calbak 分開。

**需要確認才新增的互動**：

1. 總覽：組合現有狀態及捷徑，不新增背景監測服務或沒有資料來源的統計。
2. 一致儲存：通知政策、啟動及其他設定表單改為草稿後明確儲存。現行立即套用開關會有行為改變，不能只改畫面不改服務呼叫。
3. 離開有草稿的頁面時詢問保留／放棄；錯誤保留輸入。一般草稿只暫存在記憶體，不自動寫出敏感資料。
4. JSON 匯入增加「檔案驗證 → 列出變更範圍 → 確認套用」，不再驗證成功就立即寫入。
5. 更換管理帳密、重置、還原、清理等統一使用具體操作名稱的對話框，取消為安全預設；保留所有底層權限驗證。
6. 登入到期後停止寫入、顯示重新登入入口；可保留非機密草稿，但密碼欄清空。固定 10 分鐘規則不變，不能用捲動或操作續期。

第 02 版已補上完整外框，預設開啟「共用試算表」以便直接與使用者提供的畫面比較；全域主導覽維持現有用途，不代表本次要重做首頁或其他功能。原型的互動只示範外觀與流程：儲存、下載、匯入、登入、清理均不執行實際業務。部分對話框只展示第一步，不代表正式功能已完成。
