# 軟體更新介面

一般使用者前往「設定 → 軟體更新」，按「檢查更新」後查看目前版本、最新公開版本及更新說明。下載按鈕交由瀏覽器取得安裝檔，下載完成後由使用者開啟安裝。

管理者專區的「啟動與更新」只設定更新資訊網址，不顯示重複的版本介紹或下載操作。更新說明來自已設定來源的 `version.json` 中 `releaseNote`，支援純文字、Markdown 標題、粗體、清單與連結。即使公開版本與本機相同、或比本機舊，仍顯示說明，並標明版本關係；未提供說明時顯示替代文字，檢查失敗不保留過期結果。

更新說明採 640 DIP 以內的閱讀寬度、23 DIP 行高與分節間距。建議以 `##` 分類標題、條列功能及粗體關鍵字撰寫，完整改版網址使用具名 Markdown 連結。多行純文字舊格式會依原始換行轉為有間距的條列，「文字標籤：網址」獨立轉為連結；不自動猜測內容分類，已撰寫的 Markdown 保留原結構。此閱讀版面僅套用於軟體更新頁。

`releaseNote` 範例（JSON 字串中的換行以 `\n` 表示）：

```json
{
  "releaseNote": "## 新增功能\n- **個人提醒**：可調整通知時間。\n- 顯示版本更新內容。\n\n## 改善\n- 修正重複提示。"
}
```
