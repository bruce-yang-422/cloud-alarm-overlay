# 設定 UI／UX 重整提案

狀態：使用者已確認，2026-09-29 已套用至 WPF 程式。下方保留原始功能清點與設計決策。HTML 原型與暫存截圖已於實作完成後清理。

## 分類建議

原本九個橫向頁籤，改為三組、八個直向入口。分類依使用目的，不把每個小選項各做一頁，也不另加總覽來增加操作層級。

```text
設定
├─ 提醒通知
│  ├─ 通知音效          各等級聲音、試聽、提醒視窗預覽
│  └─ 勿擾與顯示        靜音時段、閃爍間隔、公司限制
├─ 個人偏好
│  ├─ 外觀與視窗        明暗模式、配色、視窗比例
│  ├─ 首頁與天氣        釘選數量、天氣開關與地點
│  └─ 編輯與分享        常用 emoji、分享圖片署名預設
└─ 帳號與應用程式
   ├─ Google 帳號與同步 帳號清單 → 來源清單 → 來源明細
   ├─ 軟體更新          檢查版本、更新內容、下載入口
   └─ 我的裝置          裝置識別、程式資訊；固定最後
```

保留「通知音效」與「勿擾與顯示」兩頁，因為前者控制聲音且即時儲存，後者控制排程與視覺提醒且需要驗證後儲存。合成一張很長的頁面，反而不容易理解哪些改動已生效。

Google 不再保留第三欄來源側邊選單。帳號與來源放在同一工作頁的兩段清單，點來源後以明細替換內容，頂端有「返回帳號與同步」。帳號名稱、來源名稱、連線狀態各有明確位置。

## 完整功能去向

以下依目前 XAML 與 ViewModel 清點；「目前儲存」描述現況，「新位置」是提案。未列為新增的功能均須保留。

### 提醒通知

| 現有子功能 | 目前儲存／限制 | 新位置與呈現 |
|---|---|---|
| 一般、重要、緊急、強制通知的音效開關 | 各自即時儲存 | 通知音效：四列，等級文字搭配小色標 |
| 各等級聲音選擇 | 即時儲存；沒有可用音效時不可選 | 同列寬度約 180–220 DIP 的選單 |
| 音效試聽與試聽狀態 | 操作，不改設定；音效關閉仍可試聽 | 同列「試聽」，單一就地狀態 |
| 各等級通知視窗預覽 | 不建立提醒紀錄 | 頁首「預覽提醒…」選等級，與聲音試聽區別 |
| 強制通知的行為說明 | 關閉聲音仍顯示通知 | 強制通知列一行說明，不做額外警告卡 |
| 靜音起訖時段、新增、移除 | 明確儲存；HH:mm，支援跨午夜 | 勿擾與顯示：緊湊時段列表、無時段空狀態 |
| 靜音對提醒的影響 | 個人提醒延後至結束；強制通知不受限制 | 時段列表旁一段說明 |
| 閃爍間隔，預設選項與自行輸入 | 明確儲存並驗證 | 下方「提醒顯示」區，窄數值選單與毫秒單位 |
| 公司鎖定靜音／閃爍 | 兩項可分別鎖定 | 各區顯示鎖頭與「由管理者設定」，不能用 UI 解鎖 |

### Google 帳號與同步

| 現有子功能 | 目前儲存／限制 | 新位置與呈現 |
|---|---|---|
| 帳號數量、名稱、email、連線狀態 | 即時讀取 | 帳號列表；名稱為主、email 次要，狀態靠右 |
| 新增 Google 帳號 | 瀏覽器授權；不需管理員 | 頁首「新增帳號」，開簡潔對話框 |
| 帳號命名、重新命名 | 1–40 字，確認後儲存 | 新增時設定；既有帳號更多選單「重新命名」 |
| Sheets／自有日曆讀取、Sheets 編輯權限 | 至少一種讀取；編輯另行授權 | 新增帳號對話框依用途選擇，保留 Google 同意流程 |
| 登出／解除 Google 授權 | 確認後清除本機來源與快取；解除授權還會撤銷 Google 授權 | 更多選單，確認視窗明確說明差異與影響，不刪除雲端資料 |
| 憑證自動續期 | 背景處理；失效需重新登入 | 正常時不長篇解釋；失效帳號就地提供處理入口 |
| 新增來源、依帳號建立來源 | 未儲存草稿 | 帳號列「新增來源…」→ 同一內容區顯示新來源表單 |
| 來源清單、類型、狀態、最後成功時間 | 即時讀取 | 帳號下方來源列表，可依帳號篩選（新增 UI 篩選，不改同步能力） |
| 更新狀態、全部／單一來源同步 | 現有操作；畫面可見時定期刷新狀態 | 全部同步在清單工具列；單一同步在明細頁首；避免重複底部工具列 |
| 來源名稱、類型、使用帳號 | 明確儲存 | 明細「基本資料」；辨識帳號用名稱＋email |
| 來源鎖定／解鎖 | 現況為表單編輯鎖，儲存後鎖定 | 用「編輯設定」取代不明確的鎖開關；不是管理員權限 |
| Sheet 網址／ID、讀取工作表清單、工作表選擇 | 草稿，儲存後同步 | Sheets 類型專屬「連線內容」 |
| 自有日曆清單、選擇、ID | 草稿，儲存後同步 | 日曆類型專屬「連線內容」；不宣稱支援共用日曆 |
| 啟用同步、同步間隔、包含全天行程 | 明確儲存 | 明細「同步方式」；依類型顯示適用欄位 |
| 日曆提醒初始值與個別修改說明 | 提醒沿用 Google 彈出式設定；本機可覆寫／恢復 | 明細一句提示連至「我的任務」；個別行程不塞進全域設定 |
| 手動工作表 GID、允許 Tasks 寫入 | Sheets 專屬進階；需編輯權限 | 「進階：工作表與寫入」預設收合 |
| 線上 Tasks 編輯：新增、欄位、Id 唯讀、預覽差異、寫入／刪除確認 | 限 Sheets，保留表頭及第二列說明 | 明細「管理線上任務…」開專用工作面板，避免把另一整套編輯器展開在設定表單底部 |
| 儲存、立即同步、移除來源 | 移除清除本機快取，保留雲端資料 | 儲存只在編輯時底部顯示；同步頁首；移除放更多選單 |

`GoogleSourceDraft` 還有 `ReminderMinutes`、`AllDayHour` 等資料欄位。這輪 UI 分類不新增未提供的設定入口，也不更改投影／同步語意。

### 應用程式

| 現有子功能 | 目前行為 | 新位置與呈現 |
|---|---|---|
| 目前版本、檢查更新、忙碌狀態 | 使用管理員設定的 manifest URL | 軟體更新獨立頁；一般使用者不填網址 |
| 公開版本比對、較舊／相同／較新狀態 | 三種狀態皆需正確顯示 | 單一版本摘要，不能只憑有 manifest 就宣稱有更新 |
| `version.json` 的 `releaseNote` | 現有唯讀 MarkdownView | 版本摘要下「更新內容」；標題、列表、連結有層級 |
| 沒有 releaseNote、檢查失敗、下載失敗 | 替代文案／錯誤狀態 | 一個就地訊息，不複製到全域狀態列 |
| 下載安裝程式 | 交給預設瀏覽器開啟下載網址 | 版本明確的按鈕；不假裝有內建下載進度或自動安裝 |
| 裝置識別 | 唯讀 | 我的裝置；依公司／個人模式使用合適說明，不新增自行修改 ID 的能力 |
| 程式名稱、作者、更新日期、版本 | 唯讀組件資訊 | 我的裝置下「關於」；日期標成程式更新日期，避免當成最後檢查時間 |
| 從裝置頁查看更新 | 建議新增導覽捷徑 | 連至軟體更新，不重複一份下載／releaseNote UI |

## 權限與責任邊界

| 一般設定 | 管理者專區 | 其他工作頁 |
|---|---|---|
| 個人 Google 帳號、來源、授權 | 自訂桌面 OAuth：安全與存取的小型進階入口 | 單筆行程本機提醒：我的任務 |
| 查看更新內容、下載安裝程式 | 更新 manifest URL、自動啟動 | Google 日曆線上寫回：仍為未來規劃，這輪不實作 |
| 個人天氣地點 | 公司預設地點 | 分享圖片預覽、複製、PNG 匯出：原分享視窗 |
| 允許自行調整的提醒偏好 | 靜音／閃爍鎖定政策 | 首頁釘選／取消：任務與倒數工作頁 |
| 明暗與配色 | 備份、還原、清理、重置 | — |

一般使用者使用內建 Google 登入，不需匯入 `google-desktop-oauth.local.json`。提案不新增 OAuth 設定入口，也不把公司同步來源與個人來源混在一起。

## 版面規格

- 保留程式主側欄 184 DIP 與頂部 54 DIP。設定內層導航約 184 DIP，分組標題 12、選項 14 DIP；不用等寬橫向膠囊。
- 一般內容最大寬 760 DIP；帳號清單可放寬至 920 DIP。寬視窗保留留白，不強迫下拉、開關或按鈕填滿整列。
- 頁標題 22、區段標題 15、本文 14、輔助文字 12–13 DIP；行高約 1.5。間距以 8／12／16／24 為級距。
- 控制項高約 36 DIP、一般設定列 64–76 DIP；開關約 38×22；下拉箭頭用清晰 chevron，不能依賴文字 `v`。
- 區段用標題與分隔線表達。每個區段最多一層外框，不再卡片包卡片。選中狀態用短色條／底色／字重共同表達。
- 內容區一個主要垂直捲軸，標題與有草稿時的操作列固定；導航可獨立捲動。欄位錯誤留在欄位旁。
- 有限寬度（例如 1050×680 DIP）時，設定導航改由標題旁「分類」展開；來源表單改單欄。這是正式實作時需配合現有視窗最小尺寸驗證的規則。
- 深色、高對比、鍵盤焦點、文字放大與螢幕閱讀名稱納入驗收；原型只示範深／淺色與鍵盤操作，不等於 WPF 已通過無障礙驗證。

這些是配合本程式的尺寸建議，借鑑成熟桌面設定程式的密度與層級，並非宣稱是 macOS／Windows 的強制數值。

## 儲存與操作回饋

1. 音效與外觀保留即時儲存，頁面清楚標示；失敗需就地顯示並恢復實際值，不能顯示假成功。
2. 靜音／閃爍、首頁／天氣、emoji／分享、來源表單採草稿。只有變更後才出現底部「捨棄變更／儲存變更」，不另放第二個儲存按鈕。
3. 同頁多個原本獨立的儲存方法要先驗證全部草稿，再逐組儲存。若部分失敗，已完成的群組明確標示，未完成草稿保留，不宣稱交易全有或全無。這屬後續實作項目。
4. 草稿切頁、返回來源列表或離開設定時，提示「繼續編輯／捨棄變更」；外部狀態刷新不重建正在編輯的表單。
5. 檢查更新、試聽、刷新與同步都不是「儲存設定」。按鈕忙碌時防止重入，結果只在該操作所屬位置出現一次。
6. 帳號連線／來源同步狀態是持續狀態；儲存成功是短暫操作結果。不要把相同成功文字同時顯示於內頁底部與主視窗底部。
7. 解除授權、移除來源、恢復預設等動作按實際影響提供具名確認；不使用只有「確定」且未交代對象的通用視窗。

## 實作順序與驗收

1. 拆出具名設定頁與穩定識別碼，取代 `SelectedSettingsTab`／`GoogleSettingsTabIndex = 7` 的固定索引。同步修正主視窗、Google 來源捷徑、天氣入口與相關測試。
2. 將現有內容移入新分類；軟體更新重用 `SoftwareUpdateView`，移出 `MaintenanceView`；不複製第二套檢查／下載邏輯。
3. Google 工作區移除永久第二層來源导航，保留來源草稿、選擇、狀態刷新、權限判斷、任務差異確認。線上任務專用面板重用現有服務。
4. 統一草稿／自動儲存、離頁保護及單一回饋，再調整間距、配色、控制項與窄視窗。
5. 驗證公司鎖定與個人模式、全部分類的深連結、多帳號／零帳號／來源錯誤、改名、試聽、靜音跨午夜、地點選擇與預設、emoji 上限與排序、更新三種版本與失敗情境、來源未存離頁。
6. 使用實際 WPF 視窗在 100%／150% DPI、最小尺寸／常用尺寸、深淺色下截圖與鍵盤檢查，再重新封裝。

### 本輪原型檢查

八個分類在 1180×816、1050×680、1440×900、850×700 的瀏覽器視窗中均無內容水平溢出；另以 150% 像素比例產生預覽。已檢查草稿儲存／離頁提示、來源編輯返回保護、公司鎖定、帳號改名、更新內容、深色與窄視窗導航；未修改或重新封裝正式程式。

## WPF 實作紀錄

- 使用 `SettingsPage` 與分組側邊導覽取代固定索引；八個分類依上方清單排列，裝置資訊固定最後。小視窗提供「分類」展開入口。
- 音效以緊湊設定列呈現，通知視窗預覽改為頁首選單。外觀使用三張明暗縮圖、配色色票與獨立視窗比例開關。
- 明確儲存的偏好使用底部草稿列。切換設定分類或主工作頁前確認捨棄；通知、首頁與天氣、emoji 與分享皆先驗證，再逐組記錄成功結果，失敗保留未儲存草稿。
