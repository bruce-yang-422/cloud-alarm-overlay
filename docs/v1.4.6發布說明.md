# Cloud Alarm Overlay v1.4.6

修正 Google 帳號授權失效後，重新登入會遺失本機自訂日曆提醒的問題，並改善任務清單在亮色與暗色模式的分類辨識。

## 改善項目（Changed）

- 來源標籤統一分類配色：本機為灰色、Sheets 為紫色、Google 日曆為青色；亮色與暗色模式分別使用對應色票。
- 任務清單依來源顯示分類底色，逐行交替深淺以方便閱讀，支援亮色與暗色模式；移除左側分類色條，滑鼠移入時加深或提亮底色。
- 單選與多選時整列藍色反白，左側顯示 3px 藍色選取指示線（亮色模式深藍、暗色模式淺藍），未選取時不顯示；選取後移入會進一步變色，點擊工具列後仍維持選取色，鍵盤焦點另以外框標示。
- 重要提醒改為琥珀色，強制通知加入警示圖示；不可修改的提醒加入鎖頭，保留開關狀態的辨識度。
- 區分 Google 日曆與 Google Sheets 標籤，調整欄寬與輔助文字，改善窄視窗下的閱讀體驗。

## 修正問題（Fixed）

- Google 授權失效或暫時無法存取來源時，保留本機自訂的提醒開關與時間；使用「重新登入」連回同一帳號並成功同步後，會自動還原至相同行程。
- 反覆同步失敗仍會保留待還原的提醒設定。成功同步後，已取消或未再回傳的行程不會還原舊提醒。
- 主動登出帳號、移除來源或更換來源資源時，仍會清除對應的提醒設定。

## 安裝與升級

適用 **Windows x64**，安裝套件已包含 .NET 執行階段。

v1.4.5 使用者可直接執行 `CloudAlarmOverlay-v1.4.6-Setup-x64.exe` 覆蓋升級。安裝前請儲存編輯內容，建議先建立 `.calbak` 備份；資料庫會在新版啟動時自動升級。

本次修正可避免升級後再次發生設定遺失；先前已被清除的提醒設定無法自動找回。授權失效時請使用帳號的「重新登入」功能；主動登出後重新加入仍會清除原設定。
